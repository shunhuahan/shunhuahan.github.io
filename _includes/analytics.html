{%- comment -%} GoatCounter analytics. Cookieless, so no consent banner is required. To enable: set `goatcounter` in _config.yml to your site code only (the subdomain you chose at goatcounter.com), e.g. `goatcounter: shunhuahan`. Leave it blank to disable, and note that a placeholder string such as `none` counts as enabled, because Liquid treats any non-empty string as truthy. That is exactly how the old Google Analytics include ended up firing a request on every pageview with a tracking ID of "none". GoatCounter ignores requests from localhost, so local previews are not counted. {%- endcomment -%} {% if site.goatcounter and site.goatcounter != "" %} {% endif %}
